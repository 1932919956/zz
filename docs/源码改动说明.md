# 源码改动补丁

这个文件记录了「AIROOM-绿色版」相比官方原版做的全部代码改动。

如果以后你重新下载了一份官方 AIROOM 源码（比如官方更新了版本），
想把这些功能再装回去，在源码根目录执行：

    git apply "源码改动补丁.patch"

改的是这些文件：

  src/renderer/cards.tsx             添加成员里的「API 接口（免安装）」
  src/renderer/executor-catalog.tsx  中转地址输入框泛化
  src/renderer/team.css              新表单样式
  src/shared/executor-catalog.ts     Claude Code 支持中转
  src/backend/adapters/common.ts     unquotePath（路径带引号也能用）
  src/backend/adapters/dsh.ts        用上 unquotePath
  scripts/windows-job.ps1            报错改 UTF-8（不再乱码）

注意：补丁**不包含**那两个 ACP 适配器，它们在另一个文件夹：

  C:\Users\<你的用户名>\WorkBuddy AI\2026-10-15-19-35-38\bridge\api-acp.mjs
  C:\Users\<你的用户名>\WorkBuddy AI\2026-10-15-19-35-38\bridge\wb-acp.mjs
  C:\Users\<你的用户名>\WorkBuddy AI\2026-10-15-19-35-38\bridge\plugins\*.mjs

重新打包：

    npm ci
    npx electron-builder --win --dir --config electron-builder.json

然后从 @deepseek-ai/dsh 的依赖闭包（含 peerDependencies！）把 DSH 运行时补进
resources/app/node_modules，否则「DeepSeek Harness」会报找不到 package.json。
