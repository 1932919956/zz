AIROOM 分享版 —— 使用说明
==================================

一、怎么运行
------------
把整个文件夹解压到任意位置（路径里最好别有中文和空格，例如 D:\AIROOM），
双击 `AIROOM.exe` 即可。不需要安装、不需要 Node、不需要 Python。

首次启动会：
  · 在 `%USERPROFILE%\.airoom\data` 建自己的数据目录（聊天记录、密钥都在这里）
  · 托盘常驻；关窗口只是最小化到托盘，真正退出用托盘菜单

二、自带的 AI 成员
------------------
  · `Codex / Claude / DSH` —— 需要在本机装好对应的官方 CLI 并登录，否则显示"未就绪"
  · `API 成员（免安装）` —— 只需要一个 OpenAI 兼容的接口地址 + key，不用装任何客户端

三、加一个 API 成员（推荐，最省事）
----------------------------------
1. 左下角「设置与连接」→「连接与版本」→ 添加连接 → 选「API 接口（免安装）」
2. 程序路径填：  `<你解压的位置>\bridge\api-acp.mjs`
   例如解压到 D:\AIROOM，就填  `D:\AIROOM\bridge\api-acp.mjs`
3. 环境变量里填（每行一个）：
       API_BASE=https://你的中转站/v1
       API_MODEL=模型名
       API_KEY=你的密钥
       API_STYLE=chat
4. ★ 点环境变量框下面那个「保存连接」（不是对话框底部的「保存设置」！
   很多人在这里踩坑：那个按钮只保存设置，不保存连接和密钥）
5. 回到成员卡，给它起个名字、挑个形象，就能聊了

key 填不进去的备用办法：直接编辑 `bridge\api-keys.json`，按服务地址填，
例如  { "https://api.zicc.cc": "sk-你的key" }

四、这些能力默认就有
--------------------
  · 读写文件、精确改文件、按模式找文件、搜内容
  · 执行命令（PowerShell / cmd）
  · 抓网页、联网搜索（Bing 优先，百度/360 兜底，国内可用）
  · 看图（png/jpg/webp/gif 直接给模型看）
  · 看视频（自动用 ffmpeg 抽 8 帧给模型看，适合"拆镜头"）
  · 生图（读 bridge\api-keys.json 或环境变量里的 IMAGE_BASE/IMAGE_KEY/IMAGE_MODEL）
  · 记住你说过的事（memory 插件）

文件权限默认是**全盘**。想只允许它动自己的工位目录，在环境变量里加：
       API_TOOL_SCOPE=workspace

五、几个必须知道的坑
--------------------
1. `%USERPROFILE%\.airoom\data\electron` 这个目录**千万不要删**。
   里面是系统级加密密钥，删了所有已保存的 API Key 会一起失效，只能重新填。

2. 想换新的空白环境：关掉 AIROOM，把 `%USERPROFILE%\.airoom` 整个改名备份再启动。
   不要只删里面的子目录。

3. 修改连接设置后要**开个新话题**才生效（老话题还用着旧进程）。

4. 房间里（项目会议室 / 茶歇室）成员是**只读**的：能查能看，不能改文件不能执行命令。
   要动手请去「工位」或项目的「执行」阶段。

六、目录说明
------------
  AIROOM.exe            主程序
  resources\app\        程序本体（含界面和后台）
  bridge\               API 成员的适配器，必须一起带着，否则 API 成员用不了
  bridge\plugins\       插件：联网搜索、生图、记忆、派活给 WorkBuddy
  bridge\api-keys.json  没在界面里填 key 时，可以在这里按地址填
  使用说明.txt            打包时的原始说明
  源码改动补丁.patch      相对官方版的改动（想自己改源码时用）

七、想自己改源码
----------------
补丁是相对官方 AIROOM 的 diff，打在官方仓库上即可：
    git apply 源码改动补丁.patch
然后 `npm install && npm run build`，产物在 `dist\`，
直接覆盖 `resources\app\dist` 就能看到效果（不用重新打包 exe）。
